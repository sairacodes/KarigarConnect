# 🇵🇰 Karigar Connect
### Connecting Skills. Building Trust. Creating Opportunities.

**Karigar Connect** is a bilingual skills verification and employment platform designed to connect skilled workers (Karigars) with customers across Pakistan. It promotes trusted hiring through practical skill assessments, verified reviews, digital skill passports, and AI-powered service recommendations.

---

## ✨ Key Features

- 🏅 **Skill Verification:** Practical competency assessments and verified skill badges.
- 👷 **Worker Profiles:** Digital portfolios showcasing professional skills.
- ⭐ **Trust Score:** Reputation scoring with Bronze, Silver, Gold and Platinum tiers.
- 📱 **QR Skill Passport:** Digital worker identity and verification.
- 💼 **Job Management:** Job requests, scheduling and progress tracking.
- 🤖 **AI Problem Finder:** Gemini-powered service recommendations and price estimates.
- 📸 **Proof of Work:** Customer-confirmed job evidence and photo galleries.
- 🌐 **Bilingual Interface:** English and Urdu with RTL support.
- 📊 **Admin Dashboard:** Worker management, assessments, disputes and analytics.

## 🏗️ Application Modules

| Module | Responsibilities |
|---|---|
| Worker | Profiles, skill verification, job management and digital passport |
| Customer | Worker discovery, service requests and reviews |
| Assessor | Practical assessments and competency verification |
| Admin | User management, disputes, pricing and analytics |

---

## 💾 Data Management

- **LocalStorage:** Application records, profiles, jobs, reviews and assessments.
- **IndexedDB:** Job evidence, photographs and media storage.
- **Web Crypto API:** PBKDF2-SHA256 password hashing.

*The current implementation uses browser-based storage without an external database.*

## 🚀 Getting Started

**Prerequisites:** Node.js and npm.

Clone the repository, install dependencies and start the development server:

    git clone https://github.com/YOUR-USERNAME/career.git
    cd career
    npm install
    npm run dev

Build for production:

    npm run build
